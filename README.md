# Dr. Akshay Kewlani — Profile Website

Minimal, single-file doctor profile site for Dr. Akshay Kewlani (Radiation & Clinical Oncologist, Indore).

- `index.html` — complete standalone site (no build step). Open directly or host as static site.
- `data/profile.json` — structured public facts (education, practice, contact, socials).
- `data/doctor-dossier.md` — full public research dossier compiled 2 Nov 2026.

## Publish

Broodle Build → New static site → upload `index.html` → Publish. Gives `*.brud.al` URL + SSL.

Built from public listings only (Instagram, LinkedIn, YouTube, Practo, Zospital, Justdial, AROI). Informational, not medical advice.
